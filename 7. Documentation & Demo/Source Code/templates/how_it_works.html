User Journey — Step by Step

1

User Fills the Campaign Brief

The user enters campaign details into the Ad Generator form — product name, description, USP, target audience, industry, campaign goal, tone, keywords, CTA, platforms, and optional fields like competitor and discount. All fields are validated client-side before submission.

Frontend — index.html + script.js
2

Form Data Sent to Flask Backend

On submission, JavaScript sends an asynchronous POST request to /api/generate using the Fetch API with FormData. No page reload occurs. A loading spinner with cycling messages appears while the request is in progress.

JavaScript fetch() → Flask route
3

Server-Side Validation & Safety Check

Flask validates all required fields and checks for missing platforms. Then a content safety filter scans the input for blocked terms related to illegal products, fraud, adult content, violence, and hate. If flagged, a 422 response is returned immediately without calling the AI.

app.py — validate_inputs() + is_unsafe_input()
4

Input Sanitisation with Bleach

Every single user input is passed through the sanitize() function which uses the Bleach library to strip all HTML tags (preventing XSS attacks) and enforces per-field character limits to prevent prompt injection attacks.

app.py — sanitize() using bleach.clean()
5

Structured Prompt is Built

The sanitised data is passed into build_ad_prompt() which constructs a highly structured marketing prompt. The prompt includes internal reasoning instructions using thinking tags, the full campaign brief, and precise output format requirements for each selected platform.

app.py — build_ad_prompt()
6

Groq API Called with Qwen3-32B

The prompt is sent to the Groq API using the qwen/qwen3-32b model with temperature 0.85 and max tokens 4096. The system message instructs the model to act as an expert advertising engine. Groq's hardware delivers responses in seconds.

app.py — call_groq() → Groq API
7

Markdown Response Rendered in UI

The AI returns structured Markdown. The frontend JavaScript parser converts it into formatted HTML with headings, bold text, lists, and horizontal rules — displayed in the output card below the form. Users can copy to clipboard or download as a .TXT file.

script.js — renderMarkdown() + showOutput()

Application Architecture

Frontend

index.html

Single-page application with three panels — Ad Generator, Refine Ad, and Performance Tips. Tab switching, form rendering, and output display all happen without page reloads.

Styles

style.css

Premium dark SaaS design using CSS custom properties. Deep navy background, electric violet accents, animated gradient card borders, and fully responsive layout.

Controller

script.js

Handles all interactivity — tab switching, async API calls, inline markdown rendering, loading state management, clipboard copy, and TXT file download.

Backend

app.py

Flask application with three API routes (/api/generate, /api/refine, /api/tips), prompt builders, safety filter, input sanitiser, and Groq API integration.

AI Model

Qwen3-32B

32-billion parameter open-source language model served via Groq's LPU hardware for ultra-fast inference. Supports advanced internal reasoning via thinking tags.

Security

.env + Bleach

API keys are stored in .env and never exposed to the client. Bleach sanitises all user inputs. Content safety filter blocks harmful requests before they reach the AI.

Marketing Psychology Frameworks Applied

The AI prompt instructs the model to reason through which frameworks best fit the campaign before writing. Only naturally fitting techniques are applied — never forced.

📈 AIDA (Attention, Interest, Desire, Action) 🔥 PAS (Problem, Agitate, Solution) ⭐ FAB (Features, Advantages, Benefits) 🔄 BAB (Before, After, Bridge) 📖 Storytelling ⏰ Scarcity 👥 Social Proof 😰 Loss Aversion 😮 FOMO ❤️ Emotional Selling 🏆 Authority 🎁 Reciprocity 🚨 Urgency 🤔 Curiosity Gap

Local Deployment

AdForge AI runs locally on your machine using Python and Flask. No cloud infrastructure required.

1

Open the adforge folder in VS Code and open the terminal (Ctrl + `)

2

Activate the virtual environment: venv\Scripts\activate (Windows) or source venv/bin/activate (Mac/Linux)

3

Add your Groq API key to the .env file as GROQ_API_KEY=your_key_here

4

Run python app.py — the server starts at http://localhost:5000

Public Deployment via Ngrok

Ngrok creates a secure public URL for your locally running Flask app — no hosting or server required. Anyone in the world can access your app through the ngrok URL while your app is running.

1

Make sure AdForge AI is running locally at http://localhost:5000 with python app.py

2

Install ngrok by running:

pip install pyngrok
3

Open a second terminal window (keep the first one running app.py) and run:

python ngrok_start.py
4

You will see a public URL like: https://abc123.ngrok-free.app — share this with anyone to access your app from any device or browser, anywhere in the world.

5

To stop ngrok, press Ctrl + C in the second terminal. The public URL will expire when you stop it.

⚠️ Note: The ngrok free tier URL changes every time you restart it. For a permanent URL, sign up at ngrok.com and use your authtoken.
